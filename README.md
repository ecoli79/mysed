<a name="описание-системы"></a>
## 🎯 Описание системы

MySED (My System for Electronic Documents) - это комплексная система управления документооборотом, построенная на базе современных технологий:

- **NiceGUI** - современный веб-фреймворк для создания пользовательского интерфейса
- **Camunda BPM** - платформа управления бизнес-процессами
- **Mayan EDMS** - система управления документами
- **OpenLDAP** - сервер каталогов для аутентификации и управления пользователями
- **PostgreSQL** - база данных для хранения данных
- **RabbitMQ** - брокер сообщений
- **Redis** - кэш и блокировки

Система обеспечивает полный цикл работы с документами: от создания и загрузки до ознакомления, подписания и архивирования.

- 🚀 Запуск бизнес-процессов из шаблонов
- 📝 Управление задачами пользователей
- ✅ Завершение задач с загрузкой документов
- 📊 Отслеживание статуса процессов

- 👁️ Процесс ознакомления с документами для нескольких пользователей

- ✍️ Подписание документов с использованием CryptoPro
- 🔐 Работа с сертификатами
- 📝 Комментарии к подписи
- ✅ Отслеживание статуса подписания

### Синхронизация пользователей
- 🔄 Автоматическая синхронизация пользователей между OpenLDAP и Mayan EDMS

## 🏗️ Архитектура системы

### Компоненты системы

```
┌─────────────────────────────────────────────────────────┐
│                    NiceGUI Application                  │
│  (Веб-интерфейс, страницы, компоненты)                  │
└──────────────┬──────────────────────────────────────────┘
               │
    ┌──────────┴──────────┐
    │                     │
┌───▼────────┐    ┌───────▼────────┐

└────────────┘    └────────────────┘
    │                     │
    │              ┌───────▼────────┐
    │              │  PostgreSQL   │
    └──────────────┼   (Database)  │
                   └───────────────┘
    │
┌───▼────────┐
```

### Основные сервисы

- **app** (NiceGUI) - основное веб-приложение на порту 8080
- **PostgreSQL** - база данных для Mayan EDMS и Camunda BPM
- **OpenLDAP** - сервер каталогов для аутентификации
- **phpLDAPadmin** - веб-интерфейс для управления LDAP
- **RabbitMQ** - брокер сообщений для Mayan EDMS
- **Redis** - кэш и блокировки для Mayan EDMS
- **Mayan EDMS** - система управления документами на порту 80
- **Camunda BPM** - платформа управления бизнес-процессами на порту 8081/8443
- **Elasticsearch** (опционально) - поисковый движок для Mayan

<a name="быстрый-старт"></a>
## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/ecoli79/mysed.git
cd mysed
```

### 2. Настройка переменных окружения

Создайте файл `.env` в директории `Docker-compose` (см. [ENV_SETUP.md](./Docker-compose/ENV_SETUP.md)):

```bash
cd Docker-compose
cp .env.example .env
# Отредактируйте .env и укажите необходимые параметры
```

### 3. Запуск системы

```bash
docker compose up -d
```

### 4. Доступ к приложению

После запуска система будет доступна по адресам:
- **Основное приложение**: http://localhost:8080
- **Mayan EDMS**: http://localhost:80
- **Camunda BPM**: http://localhost:8081 (HTTP) или https://localhost:8443 (HTTPS)
- **phpLDAPadmin**: https://localhost:6443
- **RabbitMQ Management**: http://localhost:15672

Подробнее см. [Docker-compose/README.md](./Docker-compose/README.md)

<a name="развертывание-через-docker-compose"></a>
## 🐳 Развертывание через Docker Compose

### Полная инструкция по развертыванию

Подробное руководство по развертыванию всех компонентов системы доступно в [Docker-compose/README.md](./Docker-compose/README.md).

### Основные команды

```bash
# Запуск всех сервисов
cd Docker-compose
docker compose up -d

# Просмотр статуса
docker compose ps

# Просмотр логов
docker compose logs -f app

# Остановка сервисов
docker compose down

# Пересборка образа приложения
docker compose build app
docker compose up -d app
```

### Резервное копирование

```bash
# Автоматическое резервное копирование PostgreSQL
docker compose --profile backup run --rm postgresql-backup

# Полное резервное копирование всех сервисов
./scripts/run-backups.sh
```

### Внешние зависимости

Система использует внешний MinIO/S3 хранилище по адресу `172.19.228.50:9000` для хранения документов Mayan EDMS.

**Важно:** Убедитесь, что:
1. MinIO сервер доступен по указанному адресу
2. Создан bucket с именем `mayan`
3. Учетные данные доступа корректны

<a name="конфигурация"></a>
## ⚙️ Конфигурация

### Переменные окружения

Основные настройки системы задаются через переменные окружения в файле `.env`:

```env
# Настройки приложения
APP_NAME=MySED
APP_PORT=8080
DEBUG=false
ENVIRONMENT=production

# Настройки Camunda
CAMUNDA_URL=https://localhost:8443
CAMUNDA_USERNAME=admin
CAMUNDA_PASSWORD=your_password
CAMUNDA_VERIFY_SSL=false

# Настройки LDAP
LDAP_SERVER=openldap
LDAP_USER=cn=admin,dc=permgp7,dc=ru
LDAP_PASSWORD=your_password

# Настройки Mayan
MAYAN_URL=http://mayan-app:8000
MAYAN_USERNAME=admin
MAYAN_PASSWORD=your_password
MAYAN_API_TOKEN=your_api_token
```

Подробнее см. [Docker-compose/ENV_SETUP.md](./Docker-compose/ENV_SETUP.md)

### Настройка логирования

Система поддерживает гибкую настройку логирования:
- Консольный вывод
- Файловое логирование с ротацией
- Логирование в базу данных (SQLite/PostgreSQL)
- Структурированное JSON логирование

Подробнее см. [app_logging/LOGGING_GUIDE.md](./app_logging/LOGGING_GUIDE.md)

<a name="основные-модули"></a>
## 🔧 Основные модули

### Сервисы (services/)

- **camunda_connector.py** - Клиент для работы с Camunda BPM API
- **mayan_connector.py** - Клиент для работы с Mayan EDMS API
- **email_processor.py** - Обработка входящих email и извлечение документов
- **email_client.py** - IMAP клиент для получения почты
- **user_sync_manager.py** - Синхронизация пользователей между LDAP и Mayan
- **document_access_manager.py** - Управление правами доступа к документам
- **signature_manager.py** - Управление подписанием документов
- **role_manager.py** - Управление ролями и группами
- **document_hash_cache.py** - Кэширование хешей документов для проверки дубликатов

### Аутентификация (auth/)

- **ldap_auth.py** - Аутентификация через OpenLDAP
- **session_manager.py** - Управление сессиями пользователей
- **middleware.py** - Middleware для проверки аутентификации
- **token_storage.py** - Хранение токенов доступа
- **sync_users_from_olap.py** - Синхронизация пользователей из LDAP

### Страницы (pages/)

- **home_page.py** - Главная страница с задачами пользователя
- **task_completion_page.py** - Страница завершения задач
- **document_review_page.py** - Страница ознакомления с документами
- **document_signing_page.py** - Страница подписания документов
- **mayan_documents.py** - Работа с документами Mayan EDMS
- **my_processes_page.py** - Запущенные пользователем процессы
- **task_assignment_page.py** - Назначение задач
- **deploy_work.py** - Управление шаблонами процессов (для администраторов)

### Компоненты (components/)

- **document_viewer.py** - Компонент просмотра документов
- **gantt_chart.py** - Диаграмма Ганта для задач
- **loading_indicator.py** - Индикатор загрузки

### Утилиты (utils/)

- **date_utils.py** - Утилиты для работы с датами
- **task_utils.py** - Утилиты для работы с задачами
- **security.py** - Утилиты безопасности
- **aggrid_locale.py** - Локализация для AG Grid

### Логирование (app_logging/)

- **logger.py** - Основной модуль логирования
- **handlers.py** - Обработчики логов
- **database/** - Адаптеры для логирования в БД
